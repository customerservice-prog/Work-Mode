Use Work-Mode like an app

You can save this private Work-Mode website to your Home Screen. It connects to your remote assistant; it does not download a large AI model.

iPad / iPhone: In Safari, tap Share, choose Add to Home Screen, then Add.
Android: In Chrome, open the browser menu and choose Install app or Add to Home screen.
Windows: In Microsoft Edge, open the menu, choose Apps and install this site as an app. You can also use Work-Mode in the browser.

Keep your sign-in password private. The remote server must be online for tasks to work.

Choose your AI

Work-Mode can use AI running on your PC for no per-message model fee, or an OpenAI API key for a more capable paid option. You can change this later.

For free local AI, first install Ollama for Windows and open it. Then click Download AI model below. No Terminal commands are required. The model is several gigabytes and needs sufficient computer memory.
